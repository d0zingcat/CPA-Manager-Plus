# 飞书账号事件通知

完整 Manager Server 支持通过飞书自定义机器人 Webhook 发送账号事件。轻量静态面板不具备后台发送能力。通知默认关闭。管理员可以在「系统信息 → 飞书账号事件通知」配置机器人；也可使用服务端环境变量或 Secret 文件固定配置。机器人凭证不保存在浏览器持久化存储中。

## 事件与判定

- **需要重新登录**：请求采集或服务端巡检明确判定凭证过期、无效或被撤销。普通 `401/403`、地区限制、网络错误不触发。
- **认证已恢复**：同一 Provider 和 `auth_index` 后续出现成功请求或明确健康的服务端巡检结果。
- **额度耗尽**：受支持的标准化额度窗口达到 `100%`，或请求中出现明确的 Codex `usage_limit_reached` / xAI 免费额度耗尽证据。普通 `429` 不等于额度耗尽。
- **额度已恢复**：同一账号、同一窗口和模型范围出现更新的有效使用率且低于 `100%`。成功请求本身不会清除已知窗口的额度异常；到了预计重置时间也不会直接假设已经恢复。

Codex/xAI 本机巡检、手动服务端巡检及服务端定时巡检均可产生事件。本机巡检仅在连接 Manager Server 且使用管理员会话时上报标准化结果，沿用服务端去重和事件规则，不上传原始响应正文。未连接 Manager Server 的静态面板不能自行发送通知。

其他 Provider 取决于请求采集或主动额度查询是否提供了标准化证据。xAI 巡检只采用有稳定身份的周、月和按需付费额度窗口，不采用按位置编号的产品用量行。

缺失或非法百分比、已过期窗口、超过 24 小时或不满足时钟容差的观察（本机允许快 5 分钟，其他观测允许快 1 分钟），以及比当前状态更旧的证据均不会触发通知。45 分钟等长巡检结果仍可使用。同批同账号和维度只采用最新有效观测，不重放批内已经恢复的历史异常；不同批次仍分别判断状态变化。首次健康结果仅建立基线；首次新鲜的明确异常会通知。稳定 `auth_index` 是关联条件；没有该索引时跳过，重新登录后若更换索引会视为新凭证。

如果 Codex 错误只表明额度耗尽、没有指出具体窗口，通知会标记 `unknown`。其他窗口恢复不会自动清除这一未知窗口事件，避免错误地宣布整个账号已恢复。

本功能的 `100%` 耗尽判定独立于账号巡检的“额度阈值”；把巡检阈值设为 `90%` 不会自动变成 90% 额度预警。自动禁用和账号处理队列开关也不控制通知。

## 页面配置

使用管理员密钥登录，打开「系统信息」中的「飞书账号事件通知」：

1. 开启通知，填写飞书自定义机器人的完整 Webhook 地址和可选签名密钥。
2. 勾选需要重新登录、认证恢复、额度耗尽、额度恢复事件。
3. 点击保存，服务端即时应用，无需重启。
4. 点击发送测试消息；每次测试至少间隔 5 秒。配置有未保存改动时禁止发送测试，避免投递到旧机器人。
5. 查看最近 20 条发送记录，包括事件、状态、尝试次数及固定错误分类。

![管理员飞书通知设置页](/img/feishu-notifications-desktop.png)

地址和签名密钥使用现有 `data.key` 加密后保存在 SQLite；接口只返回“已配置”标志，不回显凭证。留空保留已有值；移除签名密钥或移除 Webhook 需明确勾选，移除 Webhook 会一并清空签名密钥并关闭通知。只读密钥不能读取配置、修改配置、上报本机巡检或发送测试消息，页面也不显示通知设置卡片。

如果任一飞书相关环境变量或 Secret 文件路径已配置，则整组设置由环境管理，页面标记为锁定；测试发送和查看结果仍可由管理员操作。环境值优先于数据库值。

## 配置机器人

在飞书群中添加自定义机器人并取得 Webhook 地址。若启用“签名校验”，同时配置签名密钥；若启用关键词校验，可使用所有消息都会包含的关键词 `CPA Manager Plus`。协议参考[飞书官方自定义机器人文档](https://open.feishu.cn/document/client-docs/bot-v3/add-custom-bot)。

在 Manager Server 进程中设置：

```dotenv
CPA_MANAGER_FEISHU_ENABLED=true
CPA_MANAGER_FEISHU_WEBHOOK_URL_FILE=/run/secrets/feishu_webhook_url
# 机器人开启签名校验时配置；没有开启则省略。
CPA_MANAGER_FEISHU_SIGNING_SECRET_FILE=/run/secrets/feishu_signing_secret
```

两个文件分别保存完整 Webhook URL 和签名密钥，使用只读挂载，限制文件读取权限。也支持直接传入 `CPA_MANAGER_FEISHU_WEBHOOK_URL` 和 `CPA_MANAGER_FEISHU_SIGNING_SECRET`；非空直接值优先于文件。显式指定的 Secret 文件不可读或为空时拒绝启动，避免静默丢失签名配置。

只支持国内飞书 `https://open.feishu.cn/open-apis/bot/v2/hook/<token>`，暂不支持国际版 Lark（`open.larksuite.com`），不跟随 HTTP 重定向。修改环境变量后需按现有部署流程重启或重新创建 Manager Server。

## 测试与观察

配置就绪后，可显式运行与服务相同版本的命令：

```sh
cpa-manager-plus test-feishu-notification
```

该命令优先使用环境变量配置；未配置环境变量时，以只读方式读取现有 Manager 数据库和数据密钥，使用页面保存的配置。命令不创建或迁移数据库、不创建密钥、不写发送历史、不启动采集器，执行后会向真实群发送一条测试消息。需使用与服务一致的数据库路径和数据密钥配置。只有 HTTP 状态成功且飞书 JSON 业务返回码为 `0` 才报告成功。启动服务本身不会发送测试消息。

消息包含事件、Provider、账号索引、额度窗口、观察时间和可确认的预计重置时间；时间使用北京时间（UTC+08:00）。原始上游错误、Token、Management Key、Webhook URL 和签名密钥不进入消息。

通知状态与待发消息保存在当前 SQLite 数据库的 `account_health_notification_state` / `account_health_notification_outbox`。相同异常不会在本机／服务端巡检、请求采集或重启后重复入队；Codex 窗口未知的额度异常按账号和范围采用 24 小时冷却期，期满后新异常允许再次告警，期间不会延长冷却，也不会自动推断额度恢复；被关闭的事件仍更新启用期间的基线，但不发送，待发的对应事件会标记为已跳过。同一事件流保持顺序。独立发送任务每秒最多尝试一条消息，单次超时 10 秒，临时失败最多尝试 5 次（重试间隔 60、120、240、480 秒）。明确的配置或业务拒绝停止重试；失败状态保留用于排查，发送记录保留 30 天。

日志仅记录消息 ID、尝试次数和固定错误分类，不记录地址、密钥或飞书原始响应。飞书没有本功能可使用的幂等键；若已经收信后进程在确认前崩溃，或请求超时但飞书实际已收信，重试可能重复发送，不保证严格一次投递。

通知不会新增上游轮询。没有请求、主动配额查询或服务端巡检时，无法及时发现状态变化。发送失败不改变账号启停或巡检结果。

## 停用与回滚

页面管理的配置可直接关闭并保存，即时停止观察和发送。环境管理的配置将 `CPA_MANAGER_FEISHU_ENABLED=false` 并按部署流程重启，可停止观察和发送。已有数据库记录保留；重新开启会继续发送待发消息。更换机器人地址后，待发消息会发给新机器人。回退到不支持通知的旧版本时，新表可以保留，不需要删除业务数据。

## 观测与故障处理

本机和服务端巡检逐账号记录探测完成时间，使用 24 小时的新鲜度窗口，同一账号和维度按观测时间排序。本机接口允许浏览器时钟比服务端快最多 5 分钟；接受这类结果时，将健康状态和额度快照的观测时间限制在服务端接收时间以内，避免后续正常时间的观测被误判为旧证据。原始观测时间仅用于本机上报重试去重。其他服务端观测仍使用未来 1 分钟限制。

本机接口按账号采用同批最新结果，超过期限的结果不写额度历史。响应保留 accepted，并返回 acceptedCount、skippedCount 和 skippedReasons（expired、clockAhead、superseded、missingIdentity）；接收条数表示已处理结果数，不代表实际通知投递条数。页面汇总所有分批上报的跳过条数及原因，以警告提示时钟偏差或过期等问题。页面不重新上报打开页面前已完成的历史巡检。本机 Codex 额度快照同步独立于通知开关，关闭通知仍可保留新鲜的额度历史。巡检结果的 `created_at_ms` 保持入库时间含义。

共享健康缓存最多保存 16384 个事件流，重复状态仅更新内存中的最新观测时间；状态变化与待发通知在同一事务中持久化，请求事件每批最多使用一个事务。超出缓存容量的事件流回退到数据库持久化路径。重启后从最近持久化状态恢复。

数据库通知配置解密失败或 Webhook 无效时，Manager 继续启动，通知关闭，页面显示配置故障。可读取但无效的 Webhook 可直接在页面修正或移除，保存后立即清除故障并生效。配置无法读取时，可恢复原数据密钥后重启，或明确勾选替换配置并填写完整的新配置；替换时空签名密钥表示移除，不沿用无法读取的旧值。也可在明确替换后勾选移除 Webhook，清空并关闭通知。显式环境变量配置错误仍拒绝启动，页面不能修改环境配置。此降级仅限可选通知配置，不绕过其他凭证和数据库的校验。
